# Day 1: Understanding Cloud Concepts

Short and simple. The basic words you'll see everywhere in Azure.

---

## What is Cloud?

Instead of buying your own servers, you use someone else's servers over the internet and pay only for what you use.

---

## Cloud Types

- **Public Cloud** → Provider's shared infrastructure (e.g. Azure). Many customers use it.
- **Private Cloud** → Infrastructure dedicated to one organization (e.g. a bank).
- **Hybrid Cloud** → A mix of both public and private.

---

## What is Cloud Computing?

Using servers, storage, databases, and networking through the cloud instead of owning hardware.

---

## Key Vocabulary

| Term | Simple Meaning |
|------|----------------|
| **Virtualization** | One physical server split into many virtual computers |
| **Virtual Machine (VM)** | A computer made by software, not hardware |
| **API** | A way for one software to talk to another |
| **Region** | A geographic location of Azure data centers (e.g. East US) |
| **Availability Zone** | Physically separate data centers inside a region |
| **Scalability** | Add/remove resources as workload changes |
| **Elasticity** | Resources adjust automatically with demand |
| **Agility** | Create and change infrastructure in minutes |
| **High Availability** | Keep the app running with little downtime |
| **Fault Tolerance** | One part fails, the system keeps working |
| **Disaster Recovery** | Recover the app after a major outage |
| **Load Balancing** | Spread traffic evenly across servers |

---

## Quick Difference to Remember

- **Scalability** = you change capacity. **Elasticity** = it changes automatically.
- **High Availability** = stay up during failures. **Disaster Recovery** = recover after a disaster.
