# Azure Zero-to-Hero

Learn Azure from the basics to real-world Azure DevOps projects through hands-on practice.

---

## Prerequisites

- Git installed on your machine

### Basic Knowledge 

- **Linux** — basic commands and navigation
- **Docker** — images, containers, Dockerfile basics
- **Kubernetes** — pods, deployments, services, ingress
- **Jenkins** — CI/CD pipelines and Jenkinsfile basics
- **Argo CD** — GitOps-based continuous deployment

## About This Series

This repository is designed to help you learn Azure from zero and build the Azure fundamentals required for a DevOps Engineer.

The series focuses on understanding concepts clearly, working with Azure services, and applying them through hands-on projects.
